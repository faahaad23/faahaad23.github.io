# Sharif Abdulla Al Fahad — Portfolio

A responsive static portfolio built with HTML, CSS, and JavaScript, suitable for GitHub Pages.

## Before publishing
1. Replace `YOUR_EMAIL@example.com` in `index.html` with your public contact email.
2. Replace the generic GitHub and LinkedIn links with your actual profile URLs.
3. Confirm the employment dates and descriptions, especially the GoodEarth role.
4. Add links to the actual GitHub repositories for the projects, if available.
5. Add a professional profile photo if you want one (the current design intentionally uses a typographic hero card).

## Publish with GitHub Pages
1. Create a GitHub repository named `your-username.github.io` or use a repository for your portfolio.
2. Upload `index.html`, `style.css`, and `script.js` to the repository root.
3. In the repository, open **Settings → Pages** and select the main branch and root folder.
4. Save and wait for GitHub Pages to publish the website.

All content is editable directly in `index.html`.
